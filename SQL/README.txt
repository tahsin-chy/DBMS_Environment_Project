SQL DATABASE SCHEMA
----------------------

This folder contains the SQL script used to create and configure the
Environmental Database for Bangladesh.

File:
- environment_bd_schema.sql

Purpose:
The SQL script creates the database 'environment_bd' and defines the
required relational tables, primary keys, foreign keys, constraints,
and relationships among the environmental and geographical data.

Database:
- MySQL
- Database Name: environment_bd

The schema should be executed before running the ETL scripts so that
the required database tables are available for data loading.
